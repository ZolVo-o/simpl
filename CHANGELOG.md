# История изменений

Изменения проекта фиксируются в этом файле.

## Не выпущено

- Версия CLI, расширения VS Code и релизного пакета теперь синхронизируется через `VERSION`.
- Windows CI и release workflow запускают полный набор `make test`.
- Тест CLI больше не зависит от системного текста ошибки отсутствующего файла.
- Добавлен литерал `ничего` для явного представления отсутствующего значения.
- Добавлена спецификация языка Simpl 0.2.

## 0.1.0 — 2026-10-09

- Добавлены CLI-команды `run`, `compile` и `disasm`.
- Добавлены расширение VS Code, подсветка `.sim`, сниппеты и команды редактора.
- Добавлены справочник языка, учебник и примеры.
- Добавлена поддержка `попробовать` / `поймать`.
