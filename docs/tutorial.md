# Simpl за 30 минут

Этот учебник знакомит с основным синтаксисом Simpl: от вывода текста до функций, списков и обработки ошибок. Примеры сохранены также отдельными файлами в `examples/`.

## Перед началом

В корне проекта соберите код:

```sh
make
```

Важно: в текущем состоянии `./simpl` — демонстрационная программа для VM, а не запускатель файлов Simpl. Она печатает версию встроенного Python и число `42`; передать ей `.simpl` файл пока нельзя. Исходные примеры ниже соответствуют языку парсера/компилятора, но для запуска пользователю нужен интерфейс исполнения исходных файлов, которого проект ещё не предоставляет. Тесты проекта проверяют VM через C API.

## 1. Первая программа: вывод и значения

Создайте файл `привет.simpl`:

```simpl
сказать "Привет, мир!"
пусть имя = "Мира"
сказать "Рада знакомству, " + имя
```

`сказать` выводит значение. `пусть` сохраняет значение под именем, а `+` соединяет строки (и складывает числа).

## 2. Числа и выражения

```simpl
пусть цена = 12.5
пусть количество = 4
пусть итог = цена * количество
сказать итог
```

Умножение выполняется раньше сложения: выражение `2 + 3 * 4` равно `14`. Скобки позволяют явно задать порядок: `(2 + 3) * 4`.

## 3. Условия

```simpl
пусть баллы = 87
если баллы >= 60
    сказать "Зачёт"
иначе
    сказать "Попробуй ещё раз"
```

Условие — выражение. Операторы сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`. Для логических условий можно использовать `и`, `или`, `не`.

## 4. Повторение

```simpl
повторить 5 раз как шаг
    сказать шаг
```

Счётчик начинается с нуля: этот пример выводит числа от `0` до `4`.

## 5. Цикл `пока`

```simpl
пусть осталось = 3
пока осталось > 0
    сказать осталось
    осталось = осталось - 1
сказать "Старт!"
```

Следите, чтобы тело цикла меняло условие, иначе цикл может не завершиться.

## 6. Списки и перебор

```simpl
пусть покупки = ["хлеб", "яблоки", "чай"]
для каждого товар в покупки
    сказать товар
```

Элемент по индексу читается как `покупки[0]`; индексация начинается с нуля. Значение можно заменить присваиванием `покупки[0] = "сыр"`.

## 7. Словари

```simpl
пусть игрок = {"имя": "Ада", "очки": 10}
сказать игрок["имя"]
игрок["очки"] = 15
сказать игрок["очки"]
```

Ключи и значения разделяются двоеточием, пары — запятыми.

## 8. Функции

```simpl
функция приветствие(имя)
    вернуть "Привет, " + имя

сказать приветствие("Сэм")
```

Функция получает аргументы в объявленном порядке. `вернуть` передаёт результат в место вызова.

## 9. Полезные встроенные функции

```simpl
пусть части = разделить("красный,зелёный,синий", ",")
сказать длина(части)
сказать верх("simpl")
сказать соединить(части, " / ")
```

Также доступны `тип(значение)` и `низ(строка)`. В `соединить` передавайте список строк и строку-разделитель.

## 10. Ввод

```simpl
сказать "Напиши своё имя:"
пусть имя = спросить
сказать "Привет, " + имя
```

`спросить` читает одну строку. В этой версии результат остаётся строкой: если нужен числовой ввод, явного преобразования строки в число среди встроенных функций пока нет.

## 11. Перехват ошибки

```simpl
попробовать
    пусть результат = 10 / 0
поймать ошибка
    сказать "Не получилось: " + ошибка
```

Обработчик получает текст ошибки времени выполнения. Например, деление на ноль можно перехватить. Это не заменяет проверку синтаксиса: ошибки парсера и неизвестные переменные не перехватываются этим блоком.

## 12. Что попробовать дальше

Откройте примеры `examples/` и попробуйте изменить их: поменяйте условие, добавьте элементы в список, напишите функцию для вычисления площади. Полный справочник операторов и конструкций находится в [`syntax.md`](syntax.md).

Чтобы сделать учебник исполняемым от начала до конца, следующий практический шаг проекта — добавить CLI, который читает `.simpl`, вызывает лексер/парсер/компилятор и запускает байткод.
