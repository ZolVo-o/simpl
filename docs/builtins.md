# Справочник встроенных функций Simpl

Встроенные функции доступны без объявления. Все аргументы в сигнатурах обязательны; неверный тип, число аргументов или недопустимое значение вызывает ошибку во время выполнения.

## Строки и значения

### `длина(значение)`

Возвращает целое число элементов или символов. Поддерживает значения, для которых определена длина, например строки, списки и словари.

```simpl
сказать длина("Привет")
сказать длина([4, 8, 12])
```

### `тип(значение)`

Возвращает строку с названием типа: `ничего`, `логическое`, `число`, `строка`, `список` или `словарь`. Для других объектов используется системное имя типа.

```simpl
сказать тип(42)
сказать тип([1, 2])
```

### `верх(строка)` и `низ(строка)`

Возвращают копию строки в верхнем или нижнем регистре. Аргумент должен быть строкой.

```simpl
сказать верх("Привет")
сказать низ("SIMPL")
```

### `разделить(строка, разделитель)`

Разбивает строку по строке-разделителю и возвращает список частей. Оба аргумента должны быть строками.

```simpl
пусть цвета = разделить("красный,зелёный,синий", ",")
сказать цвета
```

### `соединить(список, разделитель)`

Объединяет элементы итерируемого значения в строку, вставляя между ними разделитель-строку. Обычно передают список строк; несовместимые элементы приводят к ошибке.

```simpl
сказать соединить(["красный", "синий"], " / ")
```

### `строка(значение)`

Возвращает текстовое представление значения.

```simpl
сказать строка(123)
сказать строка(да)
```

### `число(значение)`

Возвращает целое или вещественное значение без изменения либо преобразует строку с целым или вещественным числом. Логические значения не принимаются.

```simpl
сказать число("42")
сказать число("3.5")
```

### `символ(код)` и `код(символ)`

`символ` возвращает символ ASCII для целого кода от `0` до `127` включительно. `код` возвращает ASCII-код строки ровно из одного символа ASCII. Эти функции не преобразуют символы Unicode вне ASCII.

```simpl
сказать символ(65)
сказать код("Z")
```

## Списки и поиск

### `сортировать(список)`

Возвращает новую отсортированную копию списка; исходный список не меняется. Элементы должны быть сравнимы между собой (например, все числа или все строки).

```simpl
пусть числа = [3, 1, 2]
сказать сортировать(числа)
сказать числа
```

### `перемешать(список)`

Случайно переставляет элементы списка на месте и возвращает `ничего`. Список изменяется.

```simpl
пусть карты = [1, 2, 3, 4]
перемешать(карты)
сказать карты
```

### `сумма(список)`

Возвращает сумму целых и вещественных чисел. Логические значения не считаются числами; пустой список даёт `0`.

```simpl
сказать сумма([1, 2.5, 3])
```

### `минимум(список)` и `максимум(список)`

Возвращают наименьший или наибольший элемент непустого списка. Все элементы должны быть сравнимы.

```simpl
сказать минимум([4, -2, 7])
сказать максимум([4, -2, 7])
```

### `добавить(список, значение)`

Добавляет значение в конец исходного списка и возвращает `ничего`.

```simpl
пусть числа = [1, 2]
добавить(числа, 3)
сказать числа
```

### `удалить(список, индекс)`

Удаляет элемент по индексу из исходного списка и возвращает удалённое значение. Поддерживаются отрицательные индексы; индекс за пределами списка вызывает ошибку.

```simpl
пусть числа = [10, 20, 30]
сказать удалить(числа, -1)
сказать числа
```

### `содержит(контейнер, значение)`

Возвращает логическое значение, указывающее, содержится ли значение в контейнере, который поддерживает проверку вхождения.

```simpl
сказать содержит([1, 2, 3], 2)
сказать содержит("привет", "вет")
```

### `найти(строка, подстрока)` или `найти(список, значение)`

Для строки возвращает индекс первого вхождения подстроки; для списка — индекс первого равного элемента. Если совпадение не найдено, возвращает `-1`.

```simpl
сказать найти("абракадабра", "ка")
сказать найти([4, 8, 12], 8)
```

### `заменить(строка, старое, новое)`

Возвращает строку, в которой все вхождения подстроки `старое` заменены на `новое`. Все аргументы должны быть строками.

```simpl
сказать заменить("красный красный", "красный", "синий")
```

## Числа и время

### `модуль(число)`

Возвращает абсолютное значение целого или вещественного числа. Логические значения не принимаются.

```simpl
сказать модуль(-7)
```

### `круг(число)`

Округляет целое или вещественное число до целого. Значения ровно посередине округляются к ближайшему чётному целому.

```simpl
сказать круг(2.5)
сказать круг(3.5)
```

### `случайное(от, до)`

Возвращает случайное целое число в диапазоне от первой границы до второй включительно. Обе границы должны быть целыми, нижняя граница не должна превышать верхнюю.

```simpl
сказать случайное(1, 6)
```

### `время()`

Возвращает текущее время Unix в секундах как число.

```simpl
сказать время()
```

### `пауза(миллисекунды)`

Приостанавливает выполнение на указанное целое неотрицательное число миллисекунд и возвращает `ничего`.

```simpl
пауза(250)
```

## Файлы и аргументы запуска

### `читать_файл(путь)`

Читает весь текстовый файл в кодировке UTF-8 и возвращает строку. Путь задаётся строкой; ошибки открытия и чтения передаются как ошибки времени выполнения.

```simpl
пусть текст = читать_файл("заметка.txt")
сказать текст
```

### `записать_файл(путь, содержимое)`

Записывает строку в текстовый файл в кодировке UTF-8, заменяя прежнее содержимое, и возвращает `ничего`. Путь и содержимое должны быть строками.

```simpl
записать_файл("заметка.txt", "Привет, мир!")
```

### `аргументы()`

Возвращает список строк аргументов, переданных программе при запуске. Путь программы в список не входит. Поддерживается также совместимый псевдоним `arguments()`.

```simpl
сказать аргументы()
```

## Завершение программы

### `выход(код)`

Немедленно завершает программу с целым кодом завершения от `0` до `255` включительно. Функция не возвращает значение.

```simpl
выход(0)
```
