# Справочник по синтаксису Simpl

Simpl — небольшой русскоязычный язык с переменными, выражениями, блоками с отступами, функциями и коллекциями. Этот справочник описывает возможности, которые уже реализованы в текущем парсере и VM; точные правила и границы совместимости фиксирует [спецификация Simpl 0.2](specification.md).

## Запуск и текущие ограничения

Соберите проект командой `make`. CLI запускает исходный файл командой `./simpl run examples/hello.simpl`, компилирует его в байткод `.simc` через `./simpl compile examples/hello.simpl` и показывает байткод командой `./simpl disasm examples/hello.simc`. При вызове `./simpl` без команды CLI выводит подсказку использовать `simpl --help` и завершается с кодом `1`.

## Структура программы

Инструкции разделяются переводами строк. Вложенные блоки задаются отступом; используйте последовательные уровни отступа и не смешивайте табуляцию с пробелами. Комментарий начинается с `#` и продолжается до конца строки.

```simpl
# Комментарий
пусть имя = "Аня"
если имя == "Аня"
    сказать "Привет, " + имя
иначе
    сказать "Здравствуйте"
```

Для блока требуется новая строка и отступ. Поддерживаются `если`/`иначе`, `пока`, `повторить`, `для каждого`, объявления функций и `попробовать`/`поймать`.

## Значения и переменные

Числа записываются цифрами, дробная часть отделяется точкой (`3.14`). Строки можно заключать в одинарные или двойные кавычки. Доступны логические литералы `да` и `нет`, а `ничего` обозначает отсутствие значения.

```simpl
пусть ответ = 42
пусть сообщение = "Привет"
пусть готово = да
пусть результат = ничего
ответ = ответ + 1
сказать ответ
```

`пусть имя = выражение` объявляет переменную, а `имя = выражение` присваивает значение. Область видимости локальных переменных функции отделена от глобальных; если локальное имя не найдено, VM также проверяет глобальные переменные.

## Выражения и операторы

| Операторы | Назначение |
| --- | --- |
| `(...)` | группировка |
| `**` | возведение в степень |
| унарные `-`, `не` | смена знака, отрицание |
| `*`, `/`, `%` | умножение, деление, остаток |
| `+`, `-` | сложение и вычитание |
| `<`, `<=`, `>`, `>=` | сравнение |
| `==`, `!=` | равенство и неравенство |
| `и` | логическое И |
| `или` | логическое ИЛИ |

Приоритет убывает сверху вниз; `**` группируется справа налево. Например, `2 + 3 * 4` вычисляется как `2 + (3 * 4)`. Условия принимают значения и выражения, которые Python считает истинными или ложными.

## Условия и циклы

```simpl
если температура > 20
    сказать "Тепло"
иначе
    сказать "Прохладно"

пусть счётчик = 0
пока счётчик < 3
    сказать счётчик
    счётчик = счётчик + 1

повторить 3 раз как номер
    сказать номер
```

Цикл `повторить N раз как имя` создаёт счётчик от `0` до `N - 1`. Итерация по списку:

```simpl
для каждого слово в ["мир", "Simpl"]
    сказать слово
```

## Функции

Функции объявляются на верхнем уровне. Параметры разделяются запятыми, `вернуть` возвращает результат.

```simpl
функция квадрат(число)
    вернуть число * число

сказать квадрат(5)
```

Функции могут вызывать другие функции и самих себя. `вернуть` следует использовать внутри функции.

## Списки и словари

Списки задаются квадратными скобками, элементы разделяются запятыми. Словари — фигурными скобками с парами `ключ: значение`.

```simpl
пусть числа = [10, 20, 30]
сказать числа[1]
числа[1] = 25

пусть карточка = {"имя": "Ли", "уровень": 2}
сказать карточка["имя"]
```

Индексы Python-совместимы, поэтому индекс первого элемента списка равен `0`. Цикл `для каждого` работает с итерируемыми значениями Python; в частности, со списками.

## Встроенные функции

| Функция | Назначение |
| --- | --- |
| `длина(значение)` | длина строки, списка или другого поддерживаемого объекта |
| `тип(значение)` | человекочитаемый тип значения |
| `верх(строка)` | строка в верхнем регистре |
| `низ(строка)` | строка в нижнем регистре |
| `разделить(строка, разделитель)` | список частей строки |
| `соединить(список, разделитель)` | строка из элементов списка |
| `аргументы()` | список аргументов, переданных программе при запуске |
| `сортировать(список)` | новая копия списка, отсортированная по возрастанию |
| `сумма(список)` | сумма целых и вещественных чисел в списке; пустой список даёт `0` |
| `минимум(список)` | наименьший элемент непустого списка |
| `максимум(список)` | наибольший элемент непустого списка |
| `читать_файл(путь)` | читает текстовый файл в кодировке UTF-8 |
| `записать_файл(путь, содержимое)` | записывает текст в файл в кодировке UTF-8, заменяя прежнее содержимое |
| `время()` | текущее время Unix в секундах |
| `пауза(миллисекунды)` | приостанавливает программу на указанное число миллисекунд |
| `число(значение)` | преобразует целое или вещественное число либо строку с числом в число |
| `строка(значение)` | возвращает текстовое представление значения |
| `случайное(от, до)` | случайное целое число в заданном включительном диапазоне |
| `добавить(список, значение)` | добавляет значение в конец списка и возвращает `ничего` |
| `удалить(список, индекс)` | удаляет элемент по индексу и возвращает его |
| `содержит(контейнер, значение)` | проверяет наличие значения в контейнере |
| `найти(строка, подстрока)` | индекс первого вхождения или `-1`; также ищет значение в списке |
| `заменить(строка, старое, новое)` | заменяет все вхождения подстроки |
| `модуль(число)` | абсолютное значение целого или вещественного числа |
| `круг(число)` | округляет до целого; половинные значения округляются к ближайшему чётному |
| `символ(код)` | символ ASCII по коду от `0` до `127` |
| `код(символ)` | код ASCII для строки из одного символа |
| `перемешать(список)` | перемешивает список на месте |
| `выход(код)` | завершает программу с кодом от `0` до `255` |

Подробные ограничения и примеры всех функций приведены в [справочнике встроенных функций](builtins.md).

`верх` и `низ` принимают строку. `соединить` принимает список строк и строку-разделитель.
`аргументы()` не включает путь к файлу программы. Для совместимости также поддерживается псевдоним `arguments()`.
`сортировать` принимает список чисел или строк одного сравнимого типа; исходный список не изменяется.
`сумма` принимает только список целых и вещественных чисел; логические значения не считаются числами.
`минимум` и `максимум` требуют непустой список сравнимых значений; для пустого списка возникает ошибка.
Функции работы с файлами принимают строки. Ошибки доступа передаются как ошибки времени выполнения.
`пауза` принимает неотрицательное целое число; дробное, логическое или отрицательное значение вызывает ошибку.
`число` принимает строку, целое или вещественное число. `случайное` принимает две целые границы; нижняя граница не должна превышать верхнюю.
`добавить` и `удалить` изменяют исходный список; `удалить` принимает отрицательные индексы в обычном порядке списка. `содержит` поддерживает контейнеры с операцией проверки вхождения.
`перемешать` меняет исходный список и возвращает `ничего`. `выход` немедленно завершает программу с указанным кодом.

```simpl
сказать читать_файл("заметка.txt")
сказать записать_файл("копия.txt", "Сохранённый текст")
```

## Ввод и вывод

`сказать выражение` печатает значение и перевод строки. `спросить` читает одну строку из стандартного ввода и возвращает строку.

```simpl
сказать "Как тебя зовут?"
пусть имя = спросить
сказать "Привет, " + имя
```

## Обработка ошибок

Конструкция `попробовать` содержит блок, за которым обязательно следует `поймать имя` и блок обработчика. В переменную обработчика записывается текст Python-ошибки времени выполнения.

```simpl
попробовать
    пусть результат = 1 / 0
поймать ошибка
    сказать ошибка
```

Например, деление на ноль будет перехвачено. Ошибки синтаксиса, диагностика неизвестных переменных и внутренние ошибки VM не являются исключениями этого `попробовать`.

## Имена и строки

Имена переменных и функций могут содержать латинские или кириллические буквы, цифры (не в начале) и подчёркивание. Ключевые слова нельзя использовать как обычные имена. Строковый лексер распознаёт обратную косую черту при поиске закрывающей кавычки, но полноценное преобразование escape-последовательностей пока не описано как поддерживаемая возможность; для переносов строк используйте отдельные инструкции.
