# Справочник по синтаксису Simpl

Simpl — небольшой русскоязычный язык с переменными, выражениями, блоками с отступами, функциями и коллекциями. Справочник описывает возможности, которые уже реализованы в текущем парсере и VM.

## Запуск и текущие ограничения

Соберите проект командой `make`. Сейчас исполняемый файл `./simpl` — демонстрация VM: он печатает версию Python runtime и число `42`. Он пока не принимает файл с исходным кодом и не предоставляет команд `compile`/`run`. Поэтому файлы из `examples/` показывают поддерживаемый исходный синтаксис, но напрямую командой `./simpl examples/hello.simpl` пока не запускаются. Не путайте это с возможностями парсера и компилятора, которые проверяются тестами проекта.

## Структура программы

Инструкции разделяются переводами строк. Вложенные блоки задаются отступом; используйте последовательные уровни отступа и не смешивайте табуляцию с пробелами. Комментарий начинается с `#` и продолжается до конца строки.

```simpl
# Комментарий
пусть имя = "Аня"
если имя == "Аня"
    сказать "Привет, " + имя
иначе
    сказать "Здравствуйте"
```

Для блока требуется новая строка и отступ. Поддерживаются `если`/`иначе`, `пока`, `повторить`, `для каждого`, объявления функций и `попробовать`/`поймать`.

## Значения и переменные

Числа записываются цифрами, дробная часть отделяется точкой (`3.14`). Строки можно заключать в одинарные или двойные кавычки. Доступны логические литералы `да` и `нет`.

```simpl
пусть ответ = 42
пусть сообщение = "Привет"
пусть готово = да
ответ = ответ + 1
сказать ответ
```

`пусть имя = выражение` объявляет переменную, а `имя = выражение` присваивает значение. Область видимости локальных переменных функции отделена от глобальных; если локальное имя не найдено, VM также проверяет глобальные переменные.

## Выражения и операторы

| Операторы | Назначение |
| --- | --- |
| `(...)` | группировка |
| `**` | возведение в степень |
| унарные `-`, `не` | смена знака, отрицание |
| `*`, `/`, `%` | умножение, деление, остаток |
| `+`, `-` | сложение и вычитание |
| `<`, `<=`, `>`, `>=` | сравнение |
| `==`, `!=` | равенство и неравенство |
| `и` | логическое И |
| `или` | логическое ИЛИ |

Приоритет убывает сверху вниз; `**` группируется справа налево. Например, `2 + 3 * 4` вычисляется как `2 + (3 * 4)`. Условия принимают значения и выражения, которые Python считает истинными или ложными.

## Условия и циклы

```simpl
если температура > 20
    сказать "Тепло"
иначе
    сказать "Прохладно"

пусть счётчик = 0
пока счётчик < 3
    сказать счётчик
    счётчик = счётчик + 1

повторить 3 раз как номер
    сказать номер
```

Цикл `повторить N раз как имя` создаёт счётчик от `0` до `N - 1`. Итерация по списку:

```simpl
для каждого слово в ["мир", "Simpl"]
    сказать слово
```

## Функции

Функции объявляются на верхнем уровне. Параметры разделяются запятыми, `вернуть` возвращает результат.

```simpl
функция квадрат(число)
    вернуть число * число

сказать квадрат(5)
```

Функции могут вызывать другие функции и самих себя. `вернуть` следует использовать внутри функции.

## Списки и словари

Списки задаются квадратными скобками, элементы разделяются запятыми. Словари — фигурными скобками с парами `ключ: значение`.

```simpl
пусть числа = [10, 20, 30]
сказать числа[1]
числа[1] = 25

пусть карточка = {"имя": "Ли", "уровень": 2}
сказать карточка["имя"]
```

Индексы Python-совместимы, поэтому индекс первого элемента списка равен `0`. Цикл `для каждого` работает с итерируемыми значениями Python; в частности, со списками.

## Встроенные функции

| Функция | Назначение |
| --- | --- |
| `длина(значение)` | длина строки, списка или другого поддерживаемого объекта |
| `тип(значение)` | человекочитаемый тип значения |
| `верх(строка)` | строка в верхнем регистре |
| `низ(строка)` | строка в нижнем регистре |
| `разделить(строка, разделитель)` | список частей строки |
| `соединить(список, разделитель)` | строка из элементов списка |

`верх` и `низ` принимают строку. `соединить` принимает список строк и строку-разделитель.

## Ввод и вывод

`сказать выражение` печатает значение и перевод строки. `спросить` читает одну строку из стандартного ввода и возвращает строку.

```simpl
сказать "Как тебя зовут?"
пусть имя = спросить
сказать "Привет, " + имя
```

## Обработка ошибок

Конструкция `попробовать` содержит блок, за которым обязательно следует `поймать имя` и блок обработчика. В переменную обработчика записывается текст Python-ошибки времени выполнения.

```simpl
попробовать
    пусть результат = 1 / 0
поймать ошибка
    сказать ошибка
```

Например, деление на ноль будет перехвачено. Ошибки синтаксиса, диагностика неизвестных переменных и внутренние ошибки VM не являются исключениями этого `попробовать`.

## Имена и строки

Имена переменных и функций могут содержать латинские или кириллические буквы, цифры (не в начале) и подчёркивание. Ключевые слова нельзя использовать как обычные имена. Строковый лексер распознаёт обратную косую черту при поиске закрывающей кавычки, но полноценное преобразование escape-последовательностей пока не описано как поддерживаемая возможность; для переносов строк используйте отдельные инструкции.
