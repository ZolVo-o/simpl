# Диагностика и исправление ошибок Simpl

Simpl показывает ошибки в stderr. Ошибки исходного кода обычно содержат имя файла, строку и столбец; ошибки во время выполнения привязаны к строке инструкции. Для `.simc` сохраняются строки исходной программы.

## Ошибка разбора и лексики

Лексер и парсер останавливают компиляцию, если встречается неизвестный символ, незакрытая строка, неверный отступ или конструкция не соответствует грамматике.

Плохо — блок `если` не имеет тела с отступом:

```simpl
если да
сказать "привет"
```

Сообщение указывает на файл и позицию, например `файл.sim:2:1: error: После «если» ожидался блок с отступом`. Команда `run` и `compile` завершаются с кодом 2.

Хорошо:

```simpl
если да
    сказать "привет"
```

Плохо — символ `@` не входит в набор операторов и знаков Simpl:

```simpl
сказать @
```

Лексер сообщает `Неизвестный символ`; замените его допустимым выражением, например `сказать 2 + 3`.

## Ошибка компиляции

Компилятор проверяет известность переменных, функций и встроенных имён. Например, вызов несуществующей функции:

```simpl
сказать неизвестная_функция()
```

Диагностика CLI указывает строку и сообщает `не удалось скомпилировать программу`; код завершения — 2. Проверьте написание имени и убедитесь, что функция объявлена в программе. Не путайте неизвестную функцию с ошибкой времени выполнения: имя функции проверяется при компиляции.

## Ошибка VM или значения во время выполнения

Деление на ноль и несовместимые типы приводят к ошибке времени выполнения. Например:

```simpl
сказать 1 / 0
```

В текущей реализации сообщение выглядит как `файл.sim:1:1: error: division by zero`; команда `run` завершается с кодом 3. Исправьте знаменатель или обработайте ошибку через `попробовать` / `поймать`.

Плохо — передана функция верхнего регистра строк, а не число:

```simpl
сказать верх(3)
```

Встроенная функция выдаёт ошибку типа с указанием строки вызова. Передайте строку:

```simpl
сказать верх("привет")
```

Необъявленная переменная также обнаруживается VM при чтении. Для похожего имени Simpl может предложить вариант:

```simpl
пусть значение = 1
сказать значние
```

Исправленный вариант:

```simpl
пусть значение = 1
сказать значение
```

Если ошибка возникла во вложенных функциях, диагностика дополняется строками стека вызовов. Эта информация сохраняется и при запуске скомпилированного `.simc`.

Ошибки времени выполнения можно перехватывать:

```simpl
попробовать
    сказать 1 / 0
поймать ошибка
    сказать ошибка
```

Сообщение ошибки становится значением переменной, указанной после `поймать`.

## Ошибки CLI и файлов

Ошибочная команда, недостающий аргумент, недоступный файл или ошибка чтения/записи завершаются с кодом 1. Проверьте `simpl --help`, написание команды и путь к файлу. Ошибка разбора/компиляции возвращает 2, ошибка VM — 3, прерывание Ctrl+C — 130.

## Куда сообщать о проблеме

Если ошибка выглядит неожиданной, сохраните исходный файл и полный текст stderr, укажите команду запуска и версию `simpl --version`. Сообщить о проблеме можно в [GitHub Issues](https://github.com/ZolVo-o/simpl/issues).
