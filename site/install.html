Установка Simpl

Выбери свою платформу. Для всех готовых бинарников потребуется совместимый Python runtime.

Важно о runtime. Опубликованные Linux- и macOS-бинарники собраны с Python 3.12; Windows-архив v0.1.0 — с Python 3.14. Архивы и установщики Simpl не включают Python runtime.

01 · LINUX X86_64

Linux

На Debian или Ubuntu можно установить готовый бинарник скриптом. Нужны glibc и Python 3.12 runtime.

curl -fsSL https://raw.githubusercontent.com/ZolVo-o/simpl/main/tools/install.sh | sh

Скрипт установит simpl в ~/.local/bin. Если каталог ещё не в PATH, скрипт покажет команду для настройки. Alpine/musl этим бинарником не поддерживается.

02 · MACOS

macOS

Установщик поддерживает Intel и Apple Silicon. Для опубликованного бинарника нужен Python 3.12 Framework от python.org.

curl -fsSL https://raw.githubusercontent.com/ZolVo-o/simpl/main/tools/install.sh | sh

Homebrew formula находится в репозитории и собирает проект из исходников под Homebrew Python 3.12. Официального tap пока нет. Склонируй репозиторий и установи formula из него:

brew install ./Formula/simpl.rb

03 · WINDOWS X64

Windows

Установщик Inno Setup подготовлен для следующего релиза, но пока не опубликован. В релизе v0.1.0 есть ZIP-архив, собранный для MSYS2 UCRT64 и Python 3.14; для стабильной установки из исходников открой терминал MSYS2 UCRT64 и выполни:

pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-python make
make
./simpl.exe run examples/hello.simpl

Уже скачанные релизы Simpl доступны на GitHub.

04 · ДЛЯ РАЗРАБОТЧИКОВ

Сборка из исходников

Нужны GCC, Make и заголовки Python. На Debian/Ubuntu:

sudo apt-get install build-essential make python3-dev
make
make test

Для Windows-сборки используй окружение MSYS2 UCRT64 и пакеты mingw-w64-ucrt-x86_64-gcc, mingw-w64-ucrt-x86_64-python и make.
