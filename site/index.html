НЕ ЕЩЁ ОДИН ЯЗЫК ДЛЯ ВСЕГО

Учебный проект, который можно читать сверху вниз — от исходного кода до байткода.

Simpl написан на C99 и использует Python runtime для значений и операций. Исходный код проходит собственные лексер, парсер и компилятор, а затем исполняется VM.

ПЕРВАЯ ПРОГРАММА · 5 МИНУТ

Выведи своё первое сообщение

Создай файл hello.simpl и сохрани в нём эти две строки:

пусть имя = "мир"
сказать "Привет, " + имя

На Linux или macOS установи Simpl этой командой:

curl -fsSL https://raw.githubusercontent.com/ZolVo-o/simpl/main/tools/install.sh | sh

Для Windows и сборки из исходников следуй инструкции для Windows. После установки запусти программу:

simpl run hello.simpl

На экране появится Привет, мир.

ВОПРОСЫ И ОТВЕТЫ

Коротко о главном.

Чем Simpl отличается от Python?

Simpl — отдельный небольшой язык с русскими ключевыми словами. Его исходный код разбирается собственным лексером и компилятором; Python используется внутри как среда для некоторых значений и операций.

Зачем нужен русский синтаксис?

Чтобы начинающим было проще сосредоточиться на переменных, условиях и алгоритмах, не изучая одновременно английские ключевые слова.

Подходит ли Simpl для настоящих проектов?

Пока это экспериментальный учебный проект. Он не предназначен для промышленного использования и его синтаксис может измениться.

Как потом перейти на другой язык?

Основные идеи — переменные, условия, циклы, функции и структуры данных — встречаются во многих языках. Изучив их здесь, можно переносить знания в Python, C и другие языки.

Кто автор и сколько людей работает над проектом?

Simpl развивается в открытом репозитории. Актуальные авторы и участники указаны в истории изменений GitHub; проект не заявляет о команде или официальной поддержке, которых нет.
