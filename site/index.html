Simpl — небольшой язык с русскими ключевыми словами. Он помогает сосредоточиться на идеях и посмотреть, как устроены лексер, компилятор и виртуальная машина.

НЕ ЕЩЁ ОДИН ЯЗЫК ДЛЯ ВСЕГО

Учебный проект, который можно читать сверху вниз — от исходного кода до байткода.

Simpl написан на C99 и использует Python runtime для значений и операций. Исходный код проходит собственные лексер, парсер и компилятор, а затем исполняется VM.
