ПЕРВЫЕ ШАГИ

Первая программа

Создайте файл привет.sim, сохраните код и запустите его командой simpl run привет.sim после установки Simpl.

пусть имя = "мир"
сказать "Привет, " + имя

Слово пусть создаёт переменную, а сказать выводит её значение. Далее попробуйте условия, циклы, списки и функции.

КРАТКИЙ СПРАВОЧНИК

Синтаксис

  • Объявление значения: пусть счёт = 10
  • Вывод: сказать счёт
  • Условия и ветви: если ..., иначе
  • Циклы: пока условие, повторить 3 раз как шаг, для каждого элемент в список
  • Функции: функция имя(аргумент) и вернуть значение
  • Списки: [1, 2, 3]; словари: {"имя": "Ада"}
  • Ошибки выполнения: блоки попробовать и поймать ошибка

Блоки отделяются отступом в четыре пробела. Строковые значения можно заключать в одинарные или двойные кавычки; комментарий начинается с #.

СПРАВОЧНИК

Встроенные функции

Функции вызываются по имени со скобками. Например, длина("кот") возвращает количество символов, а верх("привет") — строку в верхнем регистре.

  • длина, тип, строка, число
  • верх, низ, разделить, соединить, найти, заменить
  • сортировать, перемешать, сумма, минимум, максимум
  • добавить, удалить, содержит
  • модуль, круг, случайное, время, пауза
  • читать_файл, записать_файл, аргументы, символ, код, выход

ПОМОЩЬ

Как исправить ошибку

Плохо: функция ждёт строку, а получает число.

сказать верх(3)

Хорошо: передайте строку.

сказать верх("привет")

Смотрите на имя файла, строку и текст после error:. Коды завершения: 1 — команда или файл, 2 — разбор/компиляция, 3 — ошибка во время выполнения.
