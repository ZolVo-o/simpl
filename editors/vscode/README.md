# Simpl for Visual Studio Code

Это расширение регистрирует файлы `.sim` как язык Simpl, добавляет TextMate-подсветку, сниппеты и команды запуска, компиляции и просмотра байткода.

## Локальный запуск

Откройте папку `editors/vscode/` в VS Code и нажмите `F5`, чтобы запустить Extension Development Host. В новом окне создайте или откройте файл с расширением `.sim`.

`F5` запускает текущий файл, `Ctrl+B` компилирует его в `.simc`. Команда «Показать байткод Simpl» открывает дизассемблированный байткод в новой вкладке. Ошибки CLI распознаются по формату `файл:строка:столбец: error: сообщение` и попадают в панель Problems.

Настройки `simpl.path`, `simpl.autoCompileOnSave` и `simpl.showBytecode` позволяют указать исполняемый файл, включить компиляцию при сохранении и автоматически открывать байткод после компиляции.

## Упаковка

После установки Node.js и `@vscode/vsce` выполните из этой папки:

```sh
make
vsce package
code --install-extension ./simpl-0.1.0.vsix
```

Для сборки VSIX установите `@vscode/vsce` и выполните `vsce package`. Для публикации замените `publisher` в `package.json` на принадлежащий вам Marketplace Publisher ID, затем выполните `vsce publish` с настроенными учётными данными.
