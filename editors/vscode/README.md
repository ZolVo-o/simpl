# Simpl for Visual Studio Code

Это расширение регистрирует файлы `.sim` и `.simpl` как язык Simpl, добавляет TextMate-подсветку и сниппеты, а также подключает CLI-команды языка к редактору.

## Локальный запуск

Откройте папку `editors/vscode/` в VS Code и нажмите `F5`, чтобы запустить Extension Development Host. В новом окне создайте или откройте файл с расширением `.sim` либо `.simpl`.

`F5` запускает текущий файл, `Ctrl+B` компилирует его в `.simc`. Остальные действия доступны через палитру команд VS Code (`Ctrl+Shift+P`): запуск с аргументами (JSON-массив строк), компиляция в выбранный файл, проверка, форматирование, извлечение комментариев `##`, создание проекта, запуск REPL, справка/версия CLI и просмотр байткода. У дизассемблера можно выбрать `--no-names` и `--stats`. Ошибки компиляции в командах задач распознаются по формату `файл:строка:столбец: error: сообщение` и попадают в панель Problems.

TextMate-грамматика подсвечивает ключевые слова, встроенные функции, `arguments()`, числа, строки, операторы и комментарии; документирующие комментарии `##` получают отдельную область подсветки.

Настройки `simpl.path`, `simpl.autoCompileOnSave` и `simpl.showBytecode` позволяют указать исполняемый файл, включить компиляцию при сохранении и автоматически открывать байткод после компиляции.

## Упаковка

После установки Node.js и `@vscode/vsce` выполните из этой папки:

```sh
vsce package
code --install-extension ./simpl-0.2.1.vsix
```

Для сборки VSIX установите `@vscode/vsce` и выполните `vsce package`. Для публикации замените `publisher` в `package.json` на принадлежащий вам Marketplace Publisher ID, затем выполните `vsce publish` с настроенными учётными данными.
