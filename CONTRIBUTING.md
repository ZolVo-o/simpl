# Как внести вклад

Спасибо за интерес к Simpl. Перед крупным изменением откройте issue и обсудите предполагаемое поведение языка.

## Подготовка

- C-компилятор с поддержкой C99.
- GNU Make.
- Python 3 с заголовками разработки и командами `python3-config --cflags` и `python3-config --embed --ldflags`.

## Изменения

- Сохраняйте C99 и стиль проекта; сборка использует `-Wall -Wextra -Wpedantic`.
- Не используйте Python для исполнения исходного кода Simpl: Python API служит runtime-значениями и операциями.
- Сохраняйте владение `PyObject` явным и проверяйте изменения с `PYTHONMALLOC=debug ./test_compile`.
- Добавляйте тест для нового поведения и обновляйте документацию при изменении синтаксиса.

## Проверки

Запустите из корня:

```sh
make clean
make
make test
PYTHONMALLOC=debug ./test_compile
```

Для расширения VS Code дополнительно проверьте JSON-файлы и соберите VSIX командой `vsce package` из `editors/vscode/`.

## Pull request

Опишите мотивацию и поведение изменения, перечислите проверки и укажите известные ограничения. Небольшие тематические изменения проще обсуждать и рецензировать.
